# 발표 자료 (11-26 14:30)

해커톤 발표에 쓰는 자료를 모아 두는 폴더입니다. 슬라이드 · 대본 · 시연 녹화 안내 · 화면 캡처를 여기에 둡니다.

## 발표 시간
- 발표 10~15분 + 질의응답 · 피드백 10분 = 최대 25분
- 파트 5명 × 2분 30초 = 12분 30초, 소개 · 마무리 합쳐 2분 30초 안
- 대본은 한 사람당 600~700자(말하는 속도 기준)

## 발표 순서 — 예약 흐름대로
| 순서 | 내용 | 시간 |
|---|---|---|
| 0 | 프로젝트 소개 | 2분 |
| 1 | 1번 회원 · 객실 추천 — 날짜 · 인원으로 빈 객실 추천 | 2분 30초 |
| 2 | 4번 객실 예약 · 완료 — 추천에서 고른 객실 예약 | 2분 30초 |
| 3 | 5번 공통 · 예약 관리 — 관리자가 예약 승인 | 2분 30초 |
| 4 | 3번 예약 일자 관리 — 휴무 지정 → 추천 · 예약에서 막힘 | 2분 30초 |
| 5 | 2번 객실 관리 — 객실 · 사진 · 요약 카드 | 2분 30초 |
| 6 | 마무리 · 다음 단계 | 30초 |

## 파일 두는 법
- 파일 이름: `<순서>_<파트>_<내용>` (예: `1_part1_slides.pdf`, `3_part5_script.md`)
- 무거운 파일(영상 · 큰 이미지 · zip)은 올리지 않고 링크만 적습니다. 시연은 녹화 영상 링크로.
- 실명 · 비밀번호 · 키 · `.env` 값은 넣지 않습니다.
