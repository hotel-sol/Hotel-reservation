# 실제 화면 테스트 목록 (공용 `hotel`)

- 기준: main 반영 직전 dev, 2026-11-25. 공용 `hotel` 스키마(시연 데이터 40실)에 붙여 브라우저로 한 바퀴 확인합니다.
- 띄우는 법: 백엔드 `uv run fastapi run app/main.py --host 127.0.0.1 --port 8000`(환경변수 `DB_SCHEMA=hotel`) + 화면 `npm run build` → `npm run start -- -p 3000`.
- **공용 데이터를 지키는 규칙:** 새 객실은 만들지 않습니다(삭제 기능이 없어 40실이 41실이 됨). 테스트로 만든 예약은 취소, 휴무는 해제, 사진은 삭제, 바꾼 객실 값은 되돌리고, 테스트 회원은 마지막에 탈퇴합니다.
- 판정: ✅ 통과 · ❌ 실패(내용 적기) · ⏭ 건너뜀(이유)
