# placeholder — 아직 없는 화면의 임시 뼈대 페이지

상단 메뉴의 화면 5개(객실 관리 · 예약 일자 관리 · 예약 관리 · 객실 추천 · 내 예약) 중 **아직 만들어지지 않은 화면**에 "준비 중" 페이지를 띄웁니다. 로그인 후 첫 화면이나 메뉴를 눌렀을 때 404가 나지 않게 하는 용도입니다.

- 상단 메뉴(`frontend/layout`)가 함께 나오고, 관리자 화면은 관리자가 아니면 로그인 화면으로 보냅니다.
- **이미 진짜 화면이 붙은 주소는 건너뜁니다.** 각 담당 화면이 합쳐지면 자동으로 그 화면이 나옵니다.

## 붙이는 법 (메인 앱)
다른 라우터를 모두 붙인 뒤 **마지막에**:
```python
from placeholder import add_placeholders
add_placeholders(app)   # 뼈대를 붙인 주소 목록을 돌려줌
```

## 확인
```
python placeholder.py   # 진짜 화면이 있는 주소는 건너뛰는지 스스로 검사
```

모든 화면이 생기면 이 폴더를 지웁니다.
